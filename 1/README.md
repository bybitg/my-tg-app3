# MR RAGNAR — точная визуальная копия референса

## Структура проекта

- `index/` — копия HTML-страницы.
- `photo/` — исходное изображение дизайна `dashboard.jpg`.
- `code/` — CSS-оформление и JavaScript.
- `index.html` — стартовая страница в корне репозитория (нужна GitHub Pages).
- `README.md` — инструкция.

## Публикация через GitHub Pages

1. Распакуй архив.
2. Создай Public-репозиторий на GitHub.
3. Загрузи **всё содержимое** этой папки в корень репозитория: три папки, `index.html` и `README.md`.
4. Открой Settings → Pages.
5. В разделе Build and deployment выбери `Deploy from a branch`.
6. Выбери Branch `main`, Folder `/ (root)`, затем нажми Save.
7. После публикации GitHub покажет адрес сайта.

## Важно

Чтобы совпадение с картинкой было буквально пиксельным, изображение из твоего референса используется как сам экран сайта. На компьютере оно отображается в исходной пропорции 1536×864 и масштабируется по ширине на меньших экранах. Прозрачные области поверх пунктов меню реагируют на нажатие и показывают название раздела, но кошелёк, реальные котировки, вход и переводы не подключены.
